🚀 XIMA Formcycle Multiple File Upload

Robuste, native Lösung für Multiple File Uploads in Formcycle 8.4.2+

✨ Features

📎 Multiple-Upload

Echte HTML5 Multiple-File-Selection mit nativer Browser-Unterstützung

✅ Client-Validierung

Validierung VOR dem Upload spart Bandbreite und Zeit

🔌 Native Integration

Vollständige Integration mit Formcycle's AjaxUploadManager

📊 Progress-Tracking

Echtzeit-Fortschrittsanzeige für jeden Upload

📁 Inkrementell

Dateien aus verschiedenen Ordnern nacheinander hinzufügen

🎨 Responsive UI

Schöne, informative UI-Komponenten

📥 Installation

1

Script in Formcycle einbinden

Gehen Sie zu: Admin → Formulare → Ihr Formular → JavaScript

// Option 1: Externe Datei <script src="formcycle-multiple-upload.js"></script> // Option 2: Inline (Inhalt von formcycle-multiple-upload.js) <script> (function($) { // ... Script-Inhalt ... })(jQuery); </script>
2

Upload-Feld konfigurieren

Im Formcycle Form-Designer:

  1. Upload-Element hinzufügen
  2. CSS-Klasse auf custom-upload setzen
  3. Speichern
✅ Fertig! Das Script erkennt automatisch alle Upload-Felder mit der Klasse custom-upload.
3

Optional: Konfiguration anpassen

// In der formcycle-multiple-upload.js: const CONFIG = { MAX_FILE_SIZE: 10 * 1024 * 1024, // 10 MB MAX_TOTAL_SIZE: 100 * 1024 * 1024, // 100 MB MAX_FILES: 10, // Max 10 Dateien MAX_FILENAME_LENGTH: 100, // Max Länge UPLOAD_SELECTOR: '.custom-upload', // CSS-Klasse DEBUG: false // Debug-Logs };

⚙️ Wie es funktioniert

1️⃣ HTML5 Multiple-Attribut

$uploadField.prop('multiple', true);

Aktiviert native Browser-Unterstützung für Multiple-File-Selection.

2️⃣ Client-side Validierung

$uploadField.errorFunc(function() { // Validiere Dateien VOR dem Upload const files = this.files; // Prüfe: Anzahl, Größe, Duplikate, etc. for (file of files) { if (file.size > MAX_FILE_SIZE) { errors.push('Datei zu groß'); } } // Rückgabe: Fehler-String oder '' bei Erfolg return errors.length > 0 ? errorMessage : ''; });

3️⃣ Formcycle AjaxUploadManager Events

// Upload beginnt $.xutil.ajaxUpload.on('begin', function(event) { showProgress(event.fileName, 0); }); // Upload-Fortschritt $.xutil.ajaxUpload.on('progress', function(event) { const percent = (event.progress.loaded / event.progress.total) * 100; updateProgress(percent); }); // Upload erfolgreich $.xutil.ajaxUpload.on('success', function(event) { updateFileList(event.item); });

📚 API-Referenz

Formcycle AjaxUploadManager Events

Event Beschreibung Event-Daten
begin Upload startet { field, fileName, id, data }
progress Upload-Fortschritt { field, id, progress: { loaded, total } }
success Upload erfolgreich { field, id, item: FileItem }
error Upload fehlgeschlagen { field, id, error }
complete Alle Uploads fertig { field, container }
remove Datei entfernt { field, id }

🛡️ Validierung

⚠️ Wichtig: Client-side Validierung ist NICHT sicherheitsrelevant! Konfigurieren Sie zusätzlich Server-side Validierung in Formcycle.

Client-side Validierungen

Validierung Standard-Wert Beschreibung
Dateigröße 10 MB Maximale Größe pro Datei
Gesamtgröße 100 MB Maximale Gesamtgröße aller Dateien
Anzahl 10 Maximale Anzahl an Dateien
Dateiname-Länge 100 Zeichen Maximale Länge des Dateinamens
Duplikate - Verhindert doppelte Dateinamen

Server-side Validierung

Konfigurieren Sie in Formcycle:

  1. Upload-Element → Constraints → Maximale Dateigröße
  2. Upload-Element → Constraints → Erlaubte Dateitypen
  3. Formular → Einstellungen → Upload-Limits

🐛 Troubleshooting

Problem: Upload-Feld akzeptiert keine Multiple-Auswahl

Lösung:
  1. Prüfen Sie, ob CSS-Klasse custom-upload gesetzt ist
  2. Aktivieren Sie DEBUG-Modus: CONFIG.DEBUG = true
  3. Browser-Console öffnen und Logs prüfen
  4. Prüfen: $('#upload_feld').prop('multiple') sollte true sein

Problem: Keine Progress-Anzeige

Lösung:
  1. Stellen Sie sicher, dass Formcycle >= 8.4.2
  2. Prüfen: $.xutil.ajaxUpload ist definiert
  3. Console-Check: console.log($.xutil.ajaxUpload)

Problem: Events werden nicht getriggert

Lösung:
  1. Script muss NACH jQuery geladen werden
  2. Prüfen: XFC.ready() wird ausgeführt
  3. Console-Check: console.log(window.XFC)
